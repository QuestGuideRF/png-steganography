# QuestGuideRF PNG Steganography

Лёгкое статическое веб-приложение для LSB-стеганографии в браузере. Сайт позволяет спрятать текст или файл внутри изображения и затем извлечь данные обратно без сервера, прямо на стороне пользователя.

## ✨ Особенности

- Полностью работает в браузере: без Node.js, базы данных и серверной логики.
- Кодирует данные в младшие биты RGB-каналов изображения.
- Не изменяет alpha-канал.
- Перед встраиванием сжимает данные через `deflate`.
- Проверяет целостность через `SHA-256`.
- Поддерживает опциональное шифрование через `AES-GCM`.
- Умеет скрывать как текст, так и произвольные файлы.
- При кодировании принимает `PNG`, `WebP`, `BMP`, `GIF` и `JPEG`, а результат всегда сохраняет как `PNG`.
- Подходит для обычного статического хостинга, включая REG.RU.

## 🛠 Использование

### Кодирование

1. Откройте вкладку `Закодировать`.
2. Загрузите изображение-контейнер.
3. Выберите режим `текст` или `файл`.
4. Введите текст или выберите файл.
5. При необходимости укажите пароль.
6. Нажмите `Спрятать данные`.
7. Скачайте итоговый PNG.

### Извлечение

1. Откройте вкладку `Раскодировать`.
2. Загрузите изображение со скрытыми данными.
3. Если данные были зашифрованы, введите тот же пароль.
4. Нажмите `Извлечь данные`.
5. Если внутри был текст, он появится на странице. Если внутри был файл, появится ссылка на скачивание.

## Как это работает

Приложение читает изображение через `Canvas API` и работает с массивом пикселей. Для записи используются только младшие биты каналов `R`, `G` и `B`. Каждый канал хранит один бит полезной нагрузки, поэтому приблизительная вместимость вычисляется по формуле:

```text
floor(width * height * 3 / 8)
```

Перед записью данные упаковываются во внутренний контейнер:

- версия формата;
- тип содержимого: текст или файл;
- имя файла;
- MIME-тип;
- сами данные.

Затем контейнер:

1. сжимается через `deflate`;
2. при наличии пароля шифруется через `AES-GCM`;
3. получает внешний заголовок:
   - 4 байта длины полезной нагрузки;
   - 32 байта `SHA-256` хэша;
   - 1 байт флагов;
   - полезная нагрузка.

При извлечении приложение:

1. читает биты обратно из RGB;
2. извлекает заголовок;
3. проверяет длину и `SHA-256`;
4. при необходимости расшифровывает данные;
5. распаковывает `deflate`;
6. восстанавливает текст или файл.

## Ограничения

- Это стеганография, а не защита от анализа изображения.
- Без пароля данные скрыты, но не зашифрованы.
- JPEG и другие форматы с потерями могут повредить скрытые данные при повторном сохранении.
- После кодирования нужно передавать именно сгенерированный PNG.
- Для работы нужен современный браузер с поддержкой:
  - `Web Crypto API`;
  - `Canvas API`;
  - `CompressionStream` / `DecompressionStream`.
